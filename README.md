# Cho Hyunju — Product Designer Portfolio

A Japanese-language portfolio site built with HTML, CSS, and JavaScript. Project details are stored in `projects.js`; add each project's cover, app icon, and gallery images under `assets/projects/<project-slug>/`.

## Deployment

The repository is connected to Vercel. Pushing to `main` runs the static build and publishes the generated `dist/` directory.

## Local preview

Run `npm run build`, then serve the `dist/` directory with any static file server. The site has no runtime framework dependencies.
