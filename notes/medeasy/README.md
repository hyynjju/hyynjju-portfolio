# 声で使える服薬管理を目指したMedEasy

MedEasyは、高齢者など複雑なアプリ操作が難しい人に向けた、対話型のAI服薬管理サービスです。私はフロントエンド開発を担当しました。

## 課題

文字の入力や複雑な画面操作が負担となり、服薬の登録や記録を続けにくいことがあります。服薬状況を確認する家族や介護者にも、日々の確認が負担になっていました。

## 取り組み

- 音声対話で服薬予定の確認・登録・記録を行える体験
- 処方箋や薬の撮影、NFCタグを使った服薬管理
- 薬の情報や注意事項を確認できる検索機能
- 保護者とのアカウント連携と、服薬状況に応じた通知

音声だけで完結する流れに加え、撮影やタッチ操作も用意し、利用者の状況に合わせて管理できる構成を目指しました。
