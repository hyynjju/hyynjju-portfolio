# ポートフォリオサイトをリニューアルしました

[新しいポートフォリオサイト](https://www.hyynjju.com)を公開しました。

## 制作の背景

以前のサイトでは、プロジェクトを一覧で把握しにくく、情報の更新にも手間がかかっていました。また、自分の強みや人となりを十分に伝えられていないことも課題でした。

作品をひと目で確認でき、検索やフィルターで探せること、自分の考え方や強みも伝わることを目指しました。日本語・韓国語・英語に対応し、各プロジェクトに個別のURLを設けています。

## 技術と制作

プロジェクト情報や画像が中心のサイトのため、HTML・CSS・JavaScriptによる静的サイトを選びました。プロジェクト情報をデータで管理し、公開にはVercelを使用しています。

企画・デザインに2日、開発に2日をかけ、FigmaとCodex Workで制作しました。Figmaのレイアウトや余白が実装後に異なって見えることや、意図していない要素が追加されることがありました。変更箇所と維持する要素、サイズや余白を具体的に伝え、画面を確認しながら調整しました。

## 制作を通じて

約1年前に作ったサイトを改めて制作し、Codexではコードを直接編集せず、自然言語での指示を通じて実装を進められるようになったと感じました。一方、クレジットは想像以上に早く消費されるため、意図を的確に伝える効率的なプロンプトを考える必要がありました。

制作期間は10月18日から21日までの4日間です。
