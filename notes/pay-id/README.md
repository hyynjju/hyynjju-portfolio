# フォロー中のショップから探せる商品検索体験

「PAY ID」のインターンシップ課題として、アプリ内の商品検索体験を改善しました。

## 課題

購買データや検索満足度アンケート、チームメンバーへのヒアリングを通じて、フォロー中のショップで商品を探す際に、ショップごとに同じ検索を繰り返す手間があることに着目しました。

## 提案

フォロー中の複数ショップをまとめて検索できる機能と、検索結果をフォロー中のショップに絞り込めるUIを設計しました。ユーザー調査から課題設定、UI設計、プロトタイプの実装まで、5日間で取り組みました。
