# 通勤前の準備をスムーズにするOnTime

現役エンジニア3名と協働し、通勤時の出発準備を効率化するアプリ「OnTime」のUI/UXデザインとデザインシステムの設計を担当しました。

## 体験設計

目標の到着時刻を設定すると、交通状況を踏まえた出発時刻と経路を確認できます。毎回ルートを検索して出発時刻を計算する手間を減らし、日々の通勤をスムーズにすることを目指しました。

## デザインシステム

カラー、タイポグラフィ、アイコン、共通コンポーネントを整理し、各コンポーネントの種類や状態を定義しました。経路選択、場所検索、時間設定などの画面とあわせて、デザインの意図を開発メンバーが実装時に参照できる形にまとめました。
